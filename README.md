# BaggyForever 🛍️
Vintage · Antique · Thrift · Surplus — Bhopal → All India

🔗 **Live:** https://shivamgamingwithlokicraft-stack.github.io/baggy-forever/

Frontend prototype of a thrift store with:
- 3D hero (Three.js)
- Product grid + filters (search, category, size, price, sort)
- Virtual try-on (upload photo, drag/scale garment)
- Booking for in-store pickup
- Cart + demo wallet + simulated checkout
- Phone OTP login (simulated)
- Admin panel — demo login: `admin` / `baggy123`

⚠️ Prototype only. No real payments, SMS, or database. State lives in `localStorage`.

## Run locally
Open `index.html` — no build step.
